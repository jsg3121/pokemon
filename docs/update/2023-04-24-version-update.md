안녕하세요

포켓몬사이트 정식 버전으로의 업데이트를 안내드립니다.

## 업데이트 내용

### 1. window pc 필터 텍스트 사이즈 조정

- 현재 개발을 mac을 이용하여 개발하고 개발된 ui를 확인하다 보니 window에서 폰트가 달라 지정된 너비를 넘어 텍스트가 잘리는 이슈가 발생했습니다.
- 해당 부분에 대해서 너비조정, 텍스트 사이즈를 조정하여 잘리는 텍스트가 없도록 하였습니다.
- 또한 포켓몬들의 이름이 길어 모바일 버전에서는 글자가 잘려 2줄로 나오는 경우가 발생하였습니다.
- 해당 부분에 대해서도 길이의 상관없이 한 줄로 표시될 수 있도록 수정하였고 해당 부분에 대한 업데이트 사항을 기술블로그에 포스팅할 예정입니다.

### 2. font 적용

- 윈도우, 맥에서 기본으로 제공되는 폰트가 달라 두 os간 ui가 일치하지 않는 부분이 여러곳에서 발생하였습니다.
  - ex) 1번 업데이트 내용과 같은 텍스트 이슈와 버튼, 태그와 같은 컴포넌트의 사이즈 깨짐 현상
- 해당 부분의 스타일을 다시 수정하며 폰트역시 기본 제공하는 폰트가 아닌 주고 ui와 페이지 분위기에 맞는 폰트를 적용하였습니다.
  - 사용한 폰트는 **GmarketSans**폰트를 사용하였습니다.
  - 아래 링크를 통해 폰트를 다운 받을 수 있습니다.
  - https://corp.gmarket.com/fonts/

### 3. 모바일에서 필터, 포켓몬 상세 페이지가 스크롤 되는 이슈 수정

- 기존 개발시에 의도는 모바일 화면에서 페이지를 열었을 때 필터나 상세 포켓몬에 대한 정보가 스크롤 없이 화면에 꽉 채울 수 있도록 하는 방향이었습니다.
- 하지만 업데이트 후 확인했을 때 기본 모바일 브라우저에서 url정보와 함께 나타나는 상태바로 인해 화면의 크기가 상태바를 모두 포함한 height를 기준으로 ui를 그리게 되었습니다.
- 해당 부분에대해 사이트에 접속할 때 상태바의 크기를 제외한 사이즈를 측정하여 해당 사이즈 기준으로 ui를 구성하는 방법으로 수정하였습니다.

### 4. 연관 포켓몬 이동시 이전 포켓몬 정보가 표시 수정

- 9세대의 포켓몬까지 업데이트 후 포켓몬에 대한 정보를 확인했을 때 해당 이슈가 발생하였습니다.
- 해당 부분이 일어나는 경우는 다음과 같았습니다.**(예시 : 우라오스)**

  1. 메인 화면에서 우라오스의 상세 페이지로 이동합니다.
  2. 우라오스의 상세 페이지에서 연관 포켓몬인 치고마의 이미지를 클릭하여 치고마의 상세 페이지로 이동합니다.
  3. 치고마의 상세 페이지에서는 이전 포켓몬인 우라오스의 정보가 표시됩니다.
  4. url에 나타나는 id의 경우 치고마의 도감 번호로 정상적인 이동이 확인되었습니다.
  5. 해당 에러가 발생한 페이지에서 새로고침시에는 다시 정상적인 치고마 상세 정보가 나타납니다.
  6. 해당 에러는 **노말폼이 존재하는 포켓몬**에서만 발생합니다

- 해당 부분에 대한 원인은 처음 우라오스 포켓몬의 정보를 받아온 뒤 치고마의 상세 페이졸 이동했을때 내부 데이터에서는 치고마의 데이터를 가져왔지만 이전 노말폼에 대한 데이터가 남아있어 해당 정보를 표시하는 문제였습니다.
- 포켓몬 정보에 대해서 노말폼의 정보는 별개의 데이터로 관리하고 있기 때문에 해당 부분에 대한 정보를 지워주는 코드를 추가하였습니다.
- 해당 부분에 대해서도 1번 수정사항과 같이 기술 블로그에 포스팅할 예정입니다.

### 5. 리전폼, 메가진화 상태가 활성화 됐을 때 뒤로가기시 이전 포켓몬의 이미지를 불러올 수 없는 부분 수정

- 일반 포켓몬의 상세 페이지에서 리전폼이나 메가진화를 보유한 포켓몬으로 이동하였을 때 해당 부분에 대한 스위치를 활성화 한 뒤 뒤로가기시 이전 포켓몬의 이미지가 뜨지 않는 이슈가 있었습니다.
- 해당 부분에 발생 원인은 이미지파일명이 달라 발생한 이슈였습니다.
- 포켓몬의 이미지를 리전폼, 메가진화, 노말폼, 일반 포켓몬 4가지로 분류하여 파일을 저장하였는데 메가진화나 리전폼과 같은부분에 대한 값이 초기화되지 않고 저장되어 해당 값을 기준으로 파일명을 구성하여 이미지를 요청하였기 때문입니다.
- 해당 부분에서는 4번 이슈와 같이 뒤로가기를 하였을 때 상태를 체크하여 기본 상태로 되돌리는 코드를 추가하였습니다.
- 해당 부분에 대해서도 1번 수정사항과 같이 기술 블로그에 포스팅할 예정입니다.

### 추후 계획

- 현재 나와있는 모든 포켓몬과 사용함에 있어 불편함이 되는 부분에 대한 이슈는 대부분 처리되어 이용에 불편한 부분이 없다고 생각됩니다.
- 하지만 모든 디바이스, 모든 상황에서의 테스트를 하지 못하는 불가피한 상황이기에 특정 부분에서는 아직 발견하지 못한 이슈가 생길 수 있습니다.
- 해당 부분에 대해 알려주신다면 빠른 시일내에 확인 후 수정하여 업데이트 하겠습니다.

감사합니다.
