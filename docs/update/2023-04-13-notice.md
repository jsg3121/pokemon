# 공지사항

안녕하세요
이전 업데이트에서 공지했던 노말폼의 official-artwork에 대한 공지를 하려고 합니다.

이전 공지에 안내드린바와 같이 노말폼 이미지들에 대한 요청을 한 결과 official 이미지 내에서는 모든 폼들에 대한 이미지가 존재하지 않기 때문에 해당 부분에 대해서는 현재 업데이트 되어있는 방식으로 진행하게 됐습니다.

official 이미지에서는 하나의 이미지만 구성이 되어있기 때문에 official 이미지와 home 이미지 모두 사용하는 방법으로 구성하려 합니다.

## 적용 계획

1. 기존 리스트 페이지에서는 모든 폼이 아닌 기본 폼 하나의 이미지르 표시하기 때문에 해당 화면에서는 official 이미지를 사용
2. 해당 포켓몬의 detail 페이지에서는 여러 폼이 존재하기 때문에 **list페이지에 표시된 이미지를 포함하여 모든 폼을 home이미지로 적용**할 계획 입니다.
3. 해당 부분에 대한 업데이트는 다음 업데이트에 함께 적용되어 이용하실 수 있도록 할 계획 입니다.

추가적인 이용에 잘못된 부분이나 오타와 같은 수정사항을 발견하실 경우 알려주시면 바른 시일내에 수정하여 업데이트 하겠습니다.

감사합니다.
