안녕하세요

포켓몬 도감 0.2.3 버전이 업데이트 되어 업데이트 내용을 안내드립니다.

## 업데이트 내용

### 1. 7세대, 8세대 포켓몬 추가

- 7세대의 포켓몬의 수가 다른 세대에 비해 비교적 적은 포켓몬을 가지고 있어 8세대를 함께 업데이트하여 추가했습니다.
- 일부 포켓몬의 경우(자루도\_아빠) 공식적인 이로치 이미지나 이로치가 존재하지 않는 포켓몬이 있기 때문에 해당 포켓몬에 대해서는 이로치 상태에서도 기존 포켓몬의 이미지를 적용하였습니다.
- 8세대 포켓몬 마휘핑의 경우 폼의 종류가 진화시 달라지는 9종의 몸의 색상, 진화 전 마빌크의 머리장식 7종을 이용해 총 63가지의 폼이 존재합니다.
  해당 부분에 대해 모든 모습을 보여주기엔 현재 슬라이드를 이용한 노말폼 리스트 표시 방식에서는 이용에 불편함이 있을 것 같다고 판단하여 가장 눈에 띄는 **9가지의 몸의 색상 변화를 기준으로 폼을 최소화** 하였습니다.
  9가지의 방식과 머리 장식에서는 공식 일러스트로 그려진 부분을 토대로 딸기사탕공예를 적용하였습니다.

## 이후 업데이트 계획

- 9세대의 포켓몬 업데이트
- 이번 8세대를 업데이트하며 리전폼 상태에서 연관 포켓몬 페이지 이동시 이미지가 표시되지 않는 부분이 발생하여 해당 부분과 함께 추가적인 부분을 확인하고 수정해 업데이트할 계획입니다.
- 모든 포켓몬이 업데이트 되면 현재 발생 이슈를 처리 한 뒤 1.0.0 버전으로 업데이트하여 배포할 계획입니다.
  - 이슈사항
    1. os에 따라 기본 폰트가 달라져 폰트를 통일
    2. 현재 mac os기준으로 ui 구성하다보니 window에서는 화면이 잘리거나 맞지 않는 부분이 존재하여 해당 부분을 조정하는 작업이 진행될 것 입니다.

## 여담

매번 한 세대씩 업데이트 하다보니 어느덧 9세대만을 남겨두고 있습니다.
해당 업데이트 이후에 추가적인 포켓몬들이 나온다면 지속적으로 업데이트하고 관리할 예정이니 많은 관심 부탁드립니다.
감사합니다.
