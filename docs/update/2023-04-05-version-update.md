안녕하세요

포켓몬 도감 페이지 0.2.0 버전 업데이트 내용을 안내드립니다.

기존 업데이트 계획은 모든 세대의 포켓몬을 추가한 뒤 세부 수정사항이나 성능이나 기능적인 부분에 대한 최적화를 진행하려 했으나, 3세대까지의 포켓몬을 넣었음에도 로딩시간, 화면 잘림등의 이슈사항들을 먼저 개선해야 된다고 판단하여 해당 부분을 업데이트 하였습니다.

## 0.2.0 업데이트

### 1. 연관 포켓몬 스크롤 추가

- 기존 포켓몬 정보에서는 연관 포켓몬 2개의 이미지를 기준으로 영역을 구성하였습니다. 하지만 이브이나 리전폼에 따라 진화 루트가 다양해지는 포켓몬들의 경우 해당 영역에 모든 이미지를 넣었을 경우 화면을 넘어가버리는 현상이 생겼습니다.
- 해당 부분에 대한 수정으로 2개 이상의 연관 포켓몬이 존재하는 경우 내주에 스크롤을 적용하여 화면을 넘겨 확인하실 수 있도록 업데이트 하였습니다.

### 2. 리스트 렌더링 최적화

- 현재 3세대까지의 포켓몬을 모두 가져 올 때 모든 포켓몬의 카드를 표시하기위해 첫 페이지 로딩시간이 3초 이상이 소요되는 부분이 존재했습니다.
- 해당 부분을 첫 화면 가장 위쪽 스크롤에 들어오는 영역만 카드를 구성하고 스크롤에 맞는 위치에 때라 실시간으로 화면을 구성하는 방식으로 최적화하여 페이지 접속시 첫 로딩시간을 단축하였습니다.

### 필터 조건 초기화 이슈 수정

- 포켓몬 검색을 위한 필터 조건이 검색된 포켓몬의 상세페이지에서 메인페이지로 돌아갈 경우 검색 조건들이 일치하지 않는 문제가 발견되었습니다.
- 검색어의 경우 검색어는 남아있지만 포켓몬 리스트는 모든 결과를 표출하거나 타입, 세대의 체크박스가 모두 선택되어있는 경우가 생겨 해당 부분에 대한 수정 작업을 진행하였습니다.
- **_해당 부분에 대한 기술적인 내용을 추후 개발 블로그 페이지에서 업데이트할 예정입니다._**

## 향후 업데이트 계획

1. 4세대 포켓몬 업데이트

   - 현재 3세대 포켓몬 캐스퐁, 테오키스와 같이 여러 모습을 가지고 있는 경우에 대한 업데이트를 진행할 계획입니다.
