안녕하세요 도감 사이트 제작자 입니다.

이번 1.2.5 버전 업뎅이트 관련 안내사항을 알려드립니다.

## 업데이트 내용

### 정렬기능 추가

이전 업데이트에서 공지했던대로 포켓몬 정보를 사용자가 직접 설정하여 정렬할 수 있도록 구성했습니다.
기본 정렬 방식은 **도감번호 오름차순**으로 설정되어 있으며 해당 부분도 설정에 있는 필터 조건 저장에 함께 저장되어 있습니다.

### 여담

이번 업데이트는 정렬기능 외에도 해당 사이트를 구성하고 있는 개발 프로젝트의 번들러를 변경하거나 일부 코드를 최적화 하는 등의 업데이트가 있었습니다.
해당 부분에 대해서는 사이트 이용을 위한 업데이트 안내보다는 개발적인 부분이기 때문에 블로그에만 해당 내용을 포스팅 할 계획 입니다.

앞으로도 많은 이용 부탁드리며 추가적인 이슈사항이나 잘못된 정보는 언제든지 알려주시면 최대한 빠른 시일내에 업데이트하여 배포하겠습니다.

감사합니다.
