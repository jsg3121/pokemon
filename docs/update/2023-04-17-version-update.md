안녕하세요

포켓몬 도감 페이지의 0.2.2 버전 업데이트 내용을 알려드립니다.

0.2.2 버전에섬는 이전 공지사항과 같이 노말폼들에 대한 이미지들 관련 수정사항과 5세대 포켓몬 추가에 대한 부분에 대해 업데이트를 진행했습니다.

## 0.2.2 업데이트

### 1. 노말 폼 이미지 및 표시 방벙 수정

- 현재 리스트 페이지나 상세 페이지에서 사용되는 이미지는 official-artwork입니다.

- 특정 포켓몬들에서는 같은 포켓몬이지만 타입과 이미지가 다른 여러가지 폼을 가진 포켓몬이 존재합니다.
  해당 포켓몬들에 대한 정보를 제공하기 위해 다른 여러 폼들에 대한 official 이미지를 가지고 있지 않아 해당 이미지에 대한 추가 요청을 진행했었습니다.
  하지만 ofiicial 이미지들에서는 여러 폼들에 대한 모든 이미지가 구성되이 있지 않다는 답변을 받았습니다.
  official 이미지가 존재하더라도 색이 다른 모습에 대한 이미지도 같이 구성해야 하는 부분과 이런 부분에 대한 요청을 기다리기에는 시간적으로나 서비스를 제공하는 부분에 있어 불편함이 많다고 생각하여 수정을 진행하였습니다.

- 해당 부분에 대한 수정사항을 안내드립니다.
  - official 이미지에 폼이 존재하는 포켓몬의 경우 기존과 같은 이미지로 구성을 하였습니다.
  - 해당 폼들에 대해 이미지가 존재하지 않을 경우 해당 이미지들은 pokemon home 이미지로 대체하여 표시하였습니다.
  - **home 이미지를 사용한 포켓몬의 경우 리스트 페이지에서는 기존 official 이미지로 화면에 표시됩니다.**
  - 해당 포켓몬의 상세 페이지로 이동할 경우 해당 페이지에서는 **default 이미지와 다른 폼에대한 이미지 모두 home 이미지로 변경되어 표시**됩니다.

### 2. 5세대 포켓몬 업데이트

- 이번 노말 폼에 대한 이미지 표시 방식을 업데이트 하며 추가적으로 5세대 포켓몬에 대한 데이터를 추가하였습니다.
- 베쓰나이와 같이 이후 세대에 진화체가 있는 경우에 해당 포켓몬의 상세 페이지 내부에서 이미지가 표시되지 않는다는 점 양해 부탁드립니다.
- 해당 부분과 같이 부족한 이미지도 모두 표시할 수 있도록 빠른 시일 내에 업데이트 하겠습니다.

### 3. (docs) 메인 페이지에서 사이트 이동 가능한 링크 추가

- 본 이용방법이나 업데이트 내용을 확인하실 수 있는 문서 페이지에서 도감 사이트로 바로 이동하실 수 있도록 링크를 추가하였습니다.
- 메인 화면에 있는 이브이 아이콘의 링크를 이용하시면 보다 쉽게 사이트 이동이 가능합니다.

## 추후 업데이트 계획

1. 현재까지 큰 이슈사항이 발견되지 않기 때문에 기존 업데이트와 같이 6세대 포켓몬부터 순차적이로 업데이트할 계획입니다.

## 여담

처음에 사이트를 만들때는 그저 개발 포트폴리오를 채우기 위한 용도로 개발을 시작했는데 사이트가 만들어져나감에 따라 지속적으로 관리하고 공유도 해서 다른 분들도 이용하시면 좋겠다는 생각이 많이 들게 되었습니다.
현재 나와있는 정보말고도 다른 정보들도 추가하며 많은걸 제공하고 싶지만 모든 부분에 대해 혼자 개발하다보니 시간적으로나 배포하기 위한 서버나 데이터베이스 비용 등이 어려운 부분이 있어 아직 많이 부족한 페이지인것 같습니다.
혼자 개발하는 부분에 대해 힘든 부분이 생겨도 포기하지 않고 꾸준히 업데이트하여 앞으로도 포켓몬을 좋아하는 분들과 함꼐 사이트를 공유하고 더 발전시킬 수 있도록 하겠습니다.

현재 문서 페이지 말고도 블로그 사이트에 기술 관련 글들을 함께 올릴 예정입니다.

사이트가 맘에 드신다면 많은 관심 부탁드리며 수정사항이 있다면 언제든지 알려주시면 빠른 시일내에 확인하여 업데이트 하겠습니다.

감사합니다.
