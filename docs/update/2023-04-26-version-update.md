안녕하세요

정식 번전 배포 후 첫 업데이트 내용을 안내 드립니다!

이번 업데이트에서는 제가 테스트를 하고 직접 사용해보며 개선하고 싶었던 기능을 추가하였습니다.

## 업데이트 내용

### 설정 기능 추가

- 기존 우측 상단에 위치해 있던 사이트의 소스코드 페이지, 개발 블로그 페이지의 링크를 설정 기능을 추가함에 따라 조정하였습니다.
- 해당 위치에는 톱니모양의 설정 아이콘이 위치해 있으며 해당 아이콘을 이용하여 기본적인 설정과 이전에 위치해 있던 링크를 추가했습니다.
- 현재 추가 된 기능은 사용자가 이용했던 검색 기록을 저장하여 이후 다시 사이트를 방문 했을 때 해당 조건에 맞게 검색된 내용을 화면에 먼저 표시할 수 있습니다.
- 이미지와 함께 보다 자세한 설명은 이용방법 페이지에 올라와 있으니 참고 부탁드립니다.
- **현재 설정을 할 수 있는 내용은 검색기록 저장 뿐이지만 해당 기능 외에도 추가적인 설정을 늘려나갈 예정입니다**

### 그 외

- 정식 버전을 달고 배포 한 뒤 도움이 되실까 하여 공유를 했는데 정말 감사하게도 많은 분들이 칭찬과 고마움을 표시해주셨습니다.
- 개인적인 이용만으로 만들어봤던 거라 주관적인 입장에서의 기능, 아주 간단한 정보만을 표시했을 뿐인데 꾸준한 관심과 사랑으로 더 많은 기능을 추가하고 개선해 나갈 수 있는 페이지가 되겠습니다.
- 감사합니다!!
