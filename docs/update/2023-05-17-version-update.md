안녕하세요

이번 1.2.3 버전의 업데이트 내용을 안내 드립니다!

## 업데이트 내용

### 종족값 추가

- 정식 배포 이후 사용자 분들 중 종족값에 대한 정보를 알고 싶어하여 해당 정보를 표시해달라는 요청이 있어 해당 데이터를 추가하여 확인하실 수 있도록 했습니다.
- 모든 포켓몬에 대한 종족값이 업데이트 되어 있으며 노말폼이나 메가진화와 같이 형태가 달라짐에 따라 종족값의 정보도 상태에 맞추어 확인하실 수 있습니다.

### 이미지 최적화

- 이전 버전까지의 이미지는 `png`형식으로 표시되고 있어 데이터의 속도에 따라 이미지가 느리게 표시되는 경우가 있었습니다.
- 이번 업데이트에서는 현재 이미지보다 가벼운 `webp`형식의 이미지를 사용함에 따라 보다 빠르게 이미지를 로딩하여 확인하실 때 불편함이 감소하게 되었습니다.

### 검색 필터에서 도감번호로 검색 가능

- 포켓몬의 이름을 검색하는 부분을 포켓몬 명 또는 도감 번호 두 가지로 검색이 가능하도록 변경하였습니다.
- 포켓몬 이름검색의 경우에는 검색하신 텍스트가 포함되어있는 포켓몬들은 표시하게 되어있지만 도감 번호로 검색을 하실 경우에는 해당 번호의 포켓몬 하나의 결과를 표시합니다.

## 추후 업데이트 계획

이번 업데이트에 추가 된 종족값을 이용하여 리스트 화면에서 정렬을 하실 수 있도록 업데이트 할 계획입니다.
정렬기능은 검색기능과 같이 사용하실 수 있도록 검색 기록으로 나와있는 리스트를 기준으로 정렬을 할 수 있도록 구성할 계획입니다.

또한 이벤트로 배포하는 여러 모습의 피카츄, 사용자가 얻을 수 없지만 정보를 확인할 수 있는 포켓몬 등을 따로 분류하여 특별한 포켓몬으로 확인하실 수 있도록 수정하겠습니다.

개발적인 부분에서는 현재 사이트를 구성하고 있는 코드를 빌드할 때 더 가볍고 최적화 되는 도구를 사용할 예정입니다.

감사합니다.
