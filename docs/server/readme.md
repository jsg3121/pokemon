# 포켓몬 도감 만들기 - 서버

### 목표

  -  데이터베이스 - postgre
  -  prisma 사용
  -  graphql 사용해보기
  -  Swagger? 로 api 정리

### 사용할 기능

1. 포켓몬 리스트 가져오기
   * 세대별
   * 가나다순
   * 타입별
     - 싱글타입
     - 듀얼타입

2. 포켓몬 정보 가져오기
   * 이름
   * 타입
   * 진화정보
   * 약점타입
   * 강점타입

3. 검색
   * 필터
     - 이름으로 검색
     - 타입으로 검색
     - 진화체 여부로 검색
   * 필터를 통해 중복 옵션 적용

4. 타입 상성 및 배수 계산기
   *  강점타입
   *  약점타입
