# 설치 후 로컬 사용 방법

## **git clone**

```bash
  git clone https://github.com/jsg3121/pokemon.git
```

## **패키지 설치**

```javascript
  client
    cd ../client
    yarn or npm install

  server
    cd ../server
    yarn or npm install
```

## **실행**

development

```javascript
  yarn dev //or npm run dev
```

production

```javascript
  production
  client
    yarn start  //or npm run start

  server
    sh build.sh
```
