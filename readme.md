# 포켓몬 도감

포켓몬들의 정보, 이로치등을 확인하실 수 있는 사이트 입니다.
기존 개인 프로젝트로만 생각하고 만들었지만 포켓몬을 좋아하는 다른 사람들도 이용할 수 있도록 공유하고 있습니다.

## ✅ 이렇게 구성되어 있어요

- Desktop & Mobile 반응형 UI
- 타입, 세대, 특징등을 이용한 필터 검색
- 필터 또는 전체 포켓몬의 간략한 정보 및 단일 포켓몬의 상세 정보

## 📚 이런 기술을 사용했어요

### Client

- `React` : 그동안 계속 사용하고 역량을 늘려가고 있는 React를 이용해 개발했습니다.
- `CSS` + `styled-components` : styled-component를 이용한 컴포넌트별로 스타일을 관리했습니다.
- `Mobx` : 필터의 조건들을 통해 변경을 바로바로 캐치하여 조건에 맞는 결과를 가져올 수 있도록 Observer 패턴의 Mobx 상태관리 라이브러리를 사용했습니다
- `react-virtuoso` : 많은 양의 리스트 UI를 최적화를 위해 보여지는 부분에 대한 컴포넌트만 렌더링할 수 있도록 사용했습니다.
- `react-slick` : 하나의 포켓몬의 정보에서 여러가지 모습의 이미지를 함께 보여줄 수 있도록 슬라이드를 이용한 UI를 구성하기 위해 사용했습니다.
- `GraphQL` : 서버와의 데이터 통신을 위해 사용했습니다!!
  
### Server, DB

- `Node.js` : 그동안 Frontend 개발을 하며 사용해왔던 언어인 `javascript`, `typescript를` 이용하여 Node를 이용해 서버를 구성했습니다
- `Prisma` + `PostgreSQL` : 포켓몬 정보에 대한 데이터베이스를 구축하는데 사용했습니다.
- `GraphQL` : Client와의 데이터 정보를 요청하고 결과를 보내줄 수 있는 통신을 위해 사용했습니다.
- `SWC` : 현재 포켓몬 사이트의 코드에 적합한 컴파일러를 고민했을 때 기존 Babel 컴파일러보다 빠른 빌드 시간으로 사용하게 되었습니다!

### ETC

- Doc 페이지는 `Docusaurus`를 이용하여 제작하였습니다!
